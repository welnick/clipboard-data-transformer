How to use this tool

A quick guide to common transformations

The basics

Paste into the left panel. The app detects common list and table formats. Select a format card below the panels, then copy the result. If detection is wrong, use the Auto detect menu beneath the input to override it.

SQL INSERT: what should I paste?

For a SQL INSERT with column names, paste a table with headers in the first row and data below it. Copy a rectangular selection directly from Excel or query results, including headers.

ID    Name    State
101   Alice   NY
102   Bob     NJ

Select SQL INSERT, check First row contains headers, and enter the destination table name. The tool generates the INSERT statement. If you only have one row of values, leave the header option unchecked.

Common pitfalls

Commas can be ambiguous: New York, NY might be one value or two. Always review the detected interpretation. Leading-zero IDs are preserved as text by default. SQL INSERT outputs text literals; it does not inspect the destination database schema or infer NULL/numeric types.

The output panel is editable. Changes to input or transformation settings will regenerate it, replacing manual edits.

Privacy & offline operation

Everything in this HTML file runs inside your browser. It does not request network resources or send pasted content to a server, and it does not save input or output in browser storage. This is not a guarantee of compliance with your workplace rules: browser extensions, managed-device monitoring, and clipboard history are outside this tool's control. Follow your employer's policies for student, medical, or other sensitive data.
